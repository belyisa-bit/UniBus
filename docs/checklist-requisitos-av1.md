# Checklist de Requisitos da AV1

## Requisitos comuns às duas opções

- [ ] 01 — Preservar tema, repositório e funcionalidades essenciais da AV1
- [ ] 02 — Substituir ou complementar dados locais por dados de API
- [ ] 03 — Usar fetch, concentrado na pasta services
- [ ] 04 — Estados visíveis: carregamento, sucesso, vazio e erro
- [ ] 05 — Ação de tentar novamente após falha recuperável
- [ ] 06 — Autenticação conforme a seção 7.4
- [ ] 07 — Pelo menos uma rota protegida
- [ ] 08 — Sessão preservada após atualizar a página, sem armazenar senha
- [ ] 09 — Logout implementado
- [ ] 10 — Tratar respostas 401 e 403 quando a API produzir esses estados
- [ ] 11 — URL-base da API centralizada em configuração
- [ ] 12 — Incluir .env.example quando houver variáveis de ambiente
- [ ] 13 — Dados de contingência compatíveis com a interface
- [ ] 14 — README atualizado: contrato, decisões, limitações e evolução
