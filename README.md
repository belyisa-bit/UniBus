# UniBus

Sistema desenvolvido para facilitar o acesso e a consulta de informações relacionadas ao transporte universitário.

## Descrição

O UniBus é um projeto desenvolvido para auxiliar estudantes no acesso às informações das linhas de transporte universitário, horários e demais informações relacionadas ao serviço.

## Tecnologias

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Maven
